# 魔兽世界·战大陆 (WoW Web Game)

一个高还原度的魔兽世界**网页版回合制 RPG**。暗黑魔兽风 UI，无需构建、无需服务器，**双击 `index.html` 即可游玩**。

![内容](https://img.shields.io/badge/种族-8-red) ![职业](https://img.shields.io/badge/职业-9-blue) ![组合](https://img.shields.io/badge/职业组合-41-orange) ![引擎](https://img.shields.io/badge/引擎-原生JS-green)

## 🎮 快速开始

```bash
# 方式一:直接双击 index.html(推荐)
# 方式二:本地服务器
cd wow-web && python -m http.server 8000
# 打开 http://localhost:8000
```

## ✨ 游戏特色

### 角色系统
- **8 大种族**：人类、矮人、暗夜精灵、侏儒（联盟）；兽人、牛头人、巨魔、亡灵（部落）
- **创建流程 UI**：阵营选择页双卡带阵营主题色（联盟蓝/部落红）、种族预览图标与「选择→」CTA；种族选择页卡片带阵营描边、圆形种族徽章与**可玩职业图标行**（一屏看清职业组合）；职业选择页卡片带**职责徽章**（坦克/治疗/输出配色）与可玩数角标
- **9 大职业**：战士、圣骑士、猎人、盗贼、牧师、萨满祭司、法师、术士、德鲁伊
- **41 种经典职业组合**（忠实还原经典旧世职业限制）
- **种族天赋**：种族天赋已全面常驻化——血性狂暴/狂暴/石像形态/影遁/逃命专家/亡灵意志/吞噬尸体/战争践踏均为被动，效果直接计入面板与战斗
- **三系天赋树**：每个职业 3 系天赋树（共 27 系），10 级起每级 1 点天赋点，强化技能伤害/治疗/持续伤害/消耗/冷却，第 3 层解锁 45 个经典天赋技能（鲁莽、气定神闲、炎爆术、冰霜新星、疾跑、肾击、暗言术：灭、死亡缠绕、地狱烈焰……），其中自身增益/防御/资源类已随通盘精简转为常驻被动，可花钱重置；天赋弹窗内置每职业 2 套推荐点法可一键分配
- **技能书**：按「职业技能 / 种族天赋 / 天赋技能」分组展示，天赋技能带所属系标签；习得被动技能时顶部展示被动机制教学（属性常驻/战斗触发/起始护盾/自动标记/开战控场，**可折叠**：点击标题栏展开/收起，默认收起减少面板占用）；玩法说明帮助面板含战斗教学（AOE 控制、击杀反噬、被动技能等新机制）
- **职业专精系统**：
  - **☠️ 盗贼毒药**：商店购买速效/致命/致残毒药，背包中涂抹到武器（20 次命中机会）。普通攻击必触发、近战技能 60% 几率触发：速效附加自然伤害、致命使目标持续中毒、致残麻痹目标降低攻击
  - **🐾 猎人宠物驯服**：战斗中「驯服野兽」可驯服生命低于 50% 的野兽，击败野兽也有 30% 几率自动驯服（宠物栏上限 8）；世界界面「🐾 宠物」面板可切换出战、放生
  - **💜 术士灵魂碎片**：每击败一个敌人收割 1 枚碎片（上限 20）。灵魂之火消耗 1 枚造成毁灭性伤害，召唤地狱火消耗 3 枚（自带嘲讽）
  - **⚒️ 装备锻造**：强化（金币 + 材料，满 +15，11 级起消耗双倍水晶）、附魔（基础 11 种 + 高级 8 种，可替换）、分解（绿色/蓝色装备 → 锻造材料）、🧪 材料合成（5 粉尘→1 精华、5 精华→1 水晶）与 🔨 装备打造（10 款蓝/紫配方），属性实时计入面板与战斗

### 战斗系统（回合制 · 高还原）
- **职业资源**：战士怒气（受击/造成伤害积攒）、盗贼能量 + 连击点、施法职业法力
- **55 个招牌技能**：火球术、寒冰箭、暗言术：痛、变羊术、腐蚀术、剔骨、致死打击、圣盾术……每个技能有法力消耗、冷却、持续伤害/治疗、增益减益
- **深度战斗公式**：命中/闪避/暴击、护甲减伤、元素抗性（火焰/冰霜/自然/暗影/神圣/奥术）
- **Buff/Debuff/DOT/HOT**：撕裂、毒蛇钉刺、恢复、真言术：盾、荆棘术……
- **控制机制**：眩晕、变羊、恐惧、定身、潜行背刺；**控制链已统一为常驻被动**——法师变羊术/冰霜新星、术士恐惧术、盗贼闷棍、牧师心灵尖啸、战士破胆怒吼、猎人冰冻陷阱/翼龙钉刺、圣骑士忏悔、牛头人战争践踏会在战斗开始时自动控制首个敌人，且被动控场不因受到伤害解除（主动施放的变羊仍受伤害解除）
- **宠物系统**：猎人的白虎与驯服野兽（战斗中驯服、宠物栏切换出战）、术士的虚空行者（嘲讽）与地狱火（碎片召唤）、萨满的石爪图腾；**🛡️ 前排挡伤**——所有召唤宠物站前排替主人抵抗伤害（敌方单体攻击优先命中宠物，嘲讽宠物优先度最高），宠物自身护甲减伤生效，主人受到保护
- **难度校准**：被动体系调整后玩家整体变强，怪物血量/攻击统一上调 `MONSTER_HP_MULT 1.1 / MONSTER_ATK_MULT 1.05`（`js/ns.js` 全局系数，`buildEnemyUnit` 应用）；`npm run sim:balance` 可对每个职业在各等级段的**通关率**做批量模拟（默认满装+推荐天赋，`--noge` 为无装备基线），用于确认职业强度仍在合理区间
- **Boss 阶段机制**：范克里夫 50% 血量狂暴 + 召唤爪牙；穆坦努斯剧毒吐息 + 再生；索瑞森大帝火焰魔法 + 狂暴，乌克兹·沙顶暗影吐息 + 狂暴
- **多目标战斗**：高等级区域遭遇双怪，点击敌方卡牌切换目标，AOE 技能

## 🧪 测试

```bash
npm install          # jsdom 为 devDependency,仅测试需要(打包/游玩不依赖)
npm test             # = node test-headless.js && node test-dom.js
```

- `test-headless.js`：数据完整性 + 战斗引擎 + 存档/锻造/声望/成就 + **燃烧的远征（外域区域/副本/任务/61-70 装备/70 级上限/经验曲线）** 等 30+ 组用例(不需要任何依赖)
- `test-dom.js`：jsdom 全流程(角色创建→世界→战斗→副本→死亡复活→存档)
- `npm run check`：校验 `index.html` 引用的 js/css 都存在、脚本加载顺序符合依赖关系、汇报首屏体积；并跑**数据交叉引用审计**（`scripts/audit-data.js`）——把「数据里定义了、玩家却拿不到」的死内容在 CI 拦下：物品/套装散件有无获取途径、每套套装最强加成能否集齐、野外怪是否都在遭遇表、区域是否全连通、副本首领与掉落是否闭环、附魔与打造材料产物是否存在、任务与成就引用是否有效；同时做**装备属性平衡审计**——低档装备不得倒挂压制高档装备（团本/声望/世界首领掉落不低于同槽位同等级商店装）、同等级同品质不得存在纯劣化重复品、装备战力随等级不回落（把装备穿到同等级参考角色上量真实输出的引擎口径）、**每件装备的属性预算落在品质预算带（±40%）内**、**传说装备预算领先同槽位同线史诗 ≥1.25× 且传说武器引擎战力领先同线 ≥1.20×**；并单独盯**槽位覆盖**（各槽位从首件装备起每个 5 级段都有可获取装备，没有“无装备可换”的等级段）与**武器伤害曲线**——物理/法系两条线每 5 级段都有武器可换、累计最优曲线 10 级后单级涨幅不得超 60%（无断崖）、同等级同品质同线的武器伤害极差不得超 1.3 倍（无同档碾压）

推送与 Pull Request 由 `.github/workflows/ci.yml` 自动跑上述检查；`release.yml` 在真正发版前也会再跑一遍 `npm test`(测试红了不会签出 APK)。

```bash
npm run bump:check   # 本地预演:本次版本会不会触发自动发版
```

## 🔄 在线更新与自动发布（GitHub Actions）

游戏内置**在线更新检查**（`js/updater.js`，仓库 [chwl66/wow-web](https://github.com/chwl66/wow-web)）：
- 进入世界界面后**每日自动检查**一次 GitHub Releases；发现新版本弹出「🔄 在线更新」弹窗，展示更新日志
- **⚡ 增量热更新（安卓端）**：免装 APK 秒级完成——下载更新清单 `update.json` → 智能选择**增量补丁**（仅变更文件，`patch-vX.Y.Z.zip`，与上一版本差量）或**全量资源包**（`www-vX.Y.Z.zip`）→ 下载 → **SHA-256 校验**（防篡改/防损坏）→ 解压到内部存储 → 切换 WebView 加载路径并自动重启，**存档保留**；补丁基准不匹配时自动回退全量包
- 热更新不可用（桌面浏览器/无插件）时回退「📦 下载 APK」完整安装，APK 覆盖安装同样保留存档
- 「⚙️ 设置 → 版本与更新」可**手动检查**，无更新时提示已是最新；无网络/请求失败时静默跳过，不影响游戏
- 版本号由 `package.json` 单点派生（`scripts/gen-version.js` 生成 `js/version.js`），与 APK 的 versionCode/versionName 完全一致

### 自动构建 & 发布 Release

`.github/workflows/release.yml`：推送 `main`/`master` 后自动执行——**当 package.json 版本高于最新已发布 Release 时**，构建签名 APK 并创建 GitHub Release（tag `vX.Y.Z` + 自动生成更新日志），同时发布在线更新产物：

| 产物 | 说明 |
|---|---|
| `app-release.apk` | 签名安装包（完整安装） |
| `update.json` | 更新清单（版本 / 全量包 / 增量补丁 / 逐文件 SHA-256） |
| `www-vX.Y.Z.zip` | 全量 Web 资源包（热更新基准） |
| `patch-vX.Y.Z.zip` | 相对上一版的**增量补丁**（仅变更/新增文件） |

普通提交（未升版本）只构建不重复发布；也可在 Actions 页手动触发。

### 首次配置（一次性）

1. **推送本仓库**到 GitHub 后，在仓库 **Settings → Secrets and variables → Actions** 添加 4 个 Secret：

   | Secret | 值（本地获取） |
   |---|---|
   | `ANDROID_KEYSTORE_BASE64` | `base64 -w0 android/keystore/wow-web-release.keystore` 的输出 |
   | `KEYSTORE_PASSWORD` | keystore 口令（见本地 `android/keystore.properties`） |
   | `KEY_ALIAS` | 密钥别名（本工程为 `wowweb`） |
   | `KEY_PASSWORD` | 密钥口令 |

2. **升级版本**：改代码后 `npm version patch`（或 `minor`/`major`）提升 `package.json` 版本 → 推送 `main`，Actions 自动构建并发布 Release（含增量补丁）。用户手机打开游戏即自动热更新，无需重新安装。

3. 用户手机安装旧版后，打开游戏即自动检测到新版本并提示下载更新。

⚠️ 4 个 Secret 缺一不可（不签名无法安装/无法覆盖更新）；`android/keystore/` 与 `android/keystore.properties` 已被 `.gitignore` 排除且**不会**随仓库上传，请务必在本地离线备份。

### 热更新实现说明

- **原生层**：`HotUpdatePlugin.java`（自研插件，`MainActivity` 注册）基于 Capacitor 官方 `Bridge.setServerBasePath()` 机制——把 WebView 资源加载路径切换到内部存储 `<files>/updates/www-<版本>/`，支持全量解压与「复制当前生效目录 + 叠加补丁」两种模式，含 zip-slip 防护与版本元信息（`.hotupdate.json`）
- **插件依赖**：`@capacitor/filesystem`（写入下载包）。编译需要 **JDK 21**（`android/app/capacitor.build.gradle` 的 `sourceCompatibility = JavaVersion.VERSION_21`）；`settings.gradle` 里的 foojay-resolver 已声明但当前没有构建请求 `java.toolchain.languageVersion`，因此它不会真的触发 JDK 下载——`sourceCompatibility` 只使用运行 Gradle 的那个 JDK，装上 JDK 21 即可
- **产物生成**：`npm run www:artifacts`（本地）或 CI 内 `scripts/update-artifacts.js`——遍历 `www/` 计算逐文件 SHA-256、与上一版清单（从上一个 Release 拉取 `update.json`）做差量生成增量补丁
- **zip 写入器**：`scripts/zip-writer.js` 为无依赖标准 ZIP 实现（node zlib deflate），安卓端 `java.util.zip.ZipInputStream` 直接兼容
