受击 hit横向抖动 5px + 红色内闪，240ms ease-out
暴击 crit同上，飘字更大更黄（关键帧相同，靠飘字区分）

出手 lunge玩家打出伤害类技能时向敌人方向前冲 7px，200ms
为什么不用 CSS class 动画：常见写法是「移除 class → 强制 offsetWidth 重排 → 加回 class」来重启动画。 但战斗中飘字很频繁（DoT、多段伤害一回合能触发好几次），每次强制同步布局会让主线程排队掉帧。 element.animate() 不需要重排就能重启，也不会和卡片的 :hover { transform } 打架，动画结束自动回到 CSS 原状态。
